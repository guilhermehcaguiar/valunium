# Bootstrap — Etapa 01

A fundação agora contém aplicativos executáveis Next.js/NestJS, workspaces, CI, testes e Prisma. O ZIP documental original foi preservado como referência; o schema de domínio foi movido intacto para `docs/architecture/schema.conceptual.prisma`.

Consulte o [README](../../README.md) para instalação e comandos, [PostgreSQL](POSTGRESQL.md) para banco nativo isolado e [relatório](ETAPA_01_REPORT.md) para resultados reais da validação.

Requisitos: Linux, Node.js 24 LTS, pnpm 10.34.9, PostgreSQL nativo quando necessário e Python 3 para a verificação documental. Não há dependência de Docker, Prettier, cloud ou serviços comerciais.

A Etapa 01 termina na fundação. Etapa 02: autenticação, usuários, carteiras e preparo público. Etapa 03: histórico/cálculos. Etapa 04: dashboard. Nenhuma etapa seguinte é iniciada automaticamente.

Prompts são fornecidos exclusivamente no chat, sem arquivos de prompt no repositório. Agentes não criam commits, pushes ou remotos.
