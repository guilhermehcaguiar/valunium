# Código de conduta

A comunidade do Valunium deve manter colaboração respeitosa e técnica. Não são aceitos assédio, discriminação, ameaças, ataques pessoais ou divulgação de dados privados.

Feedback técnico deve focar comportamentos e código, não pessoas. Para condutas graves, procure um canal privado dos mantenedores quando disponibilizado; não exponha dados pessoais em issues públicas.

Este documento é uma política comunitária inicial e pode ser substituído por um código de conduta padronizado mediante decisão documentada.
